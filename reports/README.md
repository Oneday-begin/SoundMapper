# Recorded evaluation evidence

These are selected saved experimental results from the original local run, principally 10 October 2026. They are not results generated by a fresh clone or GitHub Actions.

See ../RESULTS.md for scope, baselines, provenance, and limitations. The original full music collection, trained artifacts, checkpoints, and database are excluded. Reproducing data-dependent experiments requires the appropriate licensed audio, metadata, model provisioning, and commands in ../README.md.

Absolute local paths in JSON reports, if any, were replaced with `<local-path>` during packaging; numerical measurements were not edited. Screenshots and placement study materials are omitted from this package.
